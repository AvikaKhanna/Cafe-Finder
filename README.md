🤖 How the ML Works

A Random Forest Regressor 🌳 learns how cafe features relate to user preferences and predicts a personalized match score for each cafe.

The model uses features such as:

* 📍 Area
* 💰 Price
* ⭐ Rating
* 📶 Wi-Fi
* 🔊 Noise level
* ☕ Coffee
* 📚 Study
* 💕 Date
* 👯 Friends
* 💻 Work
* 🎂 Birthday
* 🌿 Peaceful ambience

The model is trained on simulated user/cafe pairs generated from predefined preference rules.
